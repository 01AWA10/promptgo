# PromptGo v1.3.0 发布说明（词表扩容 + 分支下沉）

> 2026-11-20 · 版本唯一来源 `engine.__version__`，组件 `VERSION` 与之同步（有测试守） · 上一版 v1.1.0
>
> v1.3.0 = v1.2.0（11-17 图像提示词）+ v1.2.1（11-18 交付热修，§4.1）+ v1.2.2（11-19 演示页拆入口，§4.2）
> + v1.2.3（11-19 演示页任务分支，§4.3）+ v1.3.0（11-20 词表扩至 325、分支下沉进组件，§4.4）。
> 接口字段未变，升级只需覆盖 `server/` 与 `web/`。

## 1. 一句话

新增**图像提示词**能力：同一句需求，识别为 `intent=image` 后输出 8 段式提示词，并按 MJ / SDXL / Flux / DALL·E 3 切换尾部写法；
带灰度开关（可一键回滚到纯文本）、本地反馈日志与双周复盘机制。**不联网、不加依赖、文本链路指标不变。**

## 2. 新增

| 能力 | 说明 |
| --- | --- |
| 图像意图与 8 段结构 | 主体/场景/构图/光线/风格/材质/技术/负面；6 类场景、324 条术语、缺省补位并标在 `defaults` |
| 平台方言 | `generic`（默认）/ `mj`（`--ar --v --style raw --no`）/ `sdxl`（`negative:` 行）/ `flux`（`; avoid`）/ `dalle3`（自然语言约束） |
| 比例与主体提取 | `16:9` / `16比9` / 竖版 均可识别；比例词不再被当主体，无主体时用场景名占位并给 `missing_subject` |
| 灰度开关 | `--enable-image on|off`；关闭后 `/v1/meta` 停止下发 `image_*`，图像需求回落文本行为 |
| 默认方言 | `--image-platform`，请求里的 `platform` 仍可覆盖 |
| 组件展示 | 场景/比例/风格/构图/光线 chips、平台下拉、有用/没用按钮 |
| 反馈通道 | `POST /v1/feedback` → 本地 JSONL（`logs/feedback.log`，4 MB 滚动），不记 IP、不联网 |
| 看板脚本 | `tools/feedback_report.py`：复制率/重试率/好评率/归因完成率 + 失败样本一键导出 |
| 验收工具 | `tools/image_eval.py`（120 条断言）、`perf_bench.py`（P95/体积门槛）、`style_matrix_check.py`（领域×风格 100 条） |

## 3. 变更（含修复）

- **模板去重**：AV/EC/PS 限定句与 S7 固定句撞词、主体已带材质时 S6 不再复述；正文长度 181–228 → 164–212。
- **主体提取**：产物词在前的句式（「做一张宣传图，秋日露营帐篷营地…」）不再把整句壳当主体。
- **术语匹配**：`match_terms()` 改为在 lower 后的文本上比对，修复 `3D 渲染` / `2.5D 插画` 永不命中。
- **提示文案**：风格冲突提示改用中文领域名（原为 `energy` 等 code）。
- **`/v1/health`** 新增 `image:{enabled,platform}` 与 `feedback` 字段。

### 4.3 v1.2.3 的内容：演示页任务分支 + 组合示例（2026-11-19）

演示页 `/demo/` 新增「普通 / 文生图」二选一，按分支收放面板选项，并补三个选项的人话说明与 10 条组合示例：

| 项 | 说明 |
| --- | --- |
| 任务分支 | 默认「普通」：面板显示模式 + 深度；切到「文生图」：只显示方案，模式与深度收起（出图时二者不生效） |
| 三项说明 | 增强模式 / 增强深度 / 增强方案，随分支只显示相关行，文案见 `docs/OPTIONS-GUIDE.md` |
| 10 条示例 | 普通 5 条（文案/代码/邮件/解释/起名）+ 文生图 5 条（通用/MJ/SDXL/Flux/DALL·E 3），点击即切分支 + 设三项 + 填输入 |
| 出图提示 | 普通分支下若识别为图像意图，不阻断出图，结果下方提示可切分支换平台参数 |

边界说明：分支**只控界面显隐**，不强制任务类型，接口字段仍为 `mode` / `intensity` / `platform`；
v1.2.3 时分支由演示页通过 Shadow DOM 控制，**v1.3.0 已下沉进组件（见 §4.4）**，该实现作废。
新增 4 条守护用例（默认分支隐藏方案、示例 5+5 分布、说明覆盖三项、出图提示），合计 318。

## 5. 升级步骤（A → A）

1. 停服务（`Ctrl+C`）。
2. 覆盖 `server/` 与 `web/`（配置文件无需改动，无数据迁移）。
3. 启动：`python server/app.py --port 7317`；确认 `/v1/health` 里 `image.enabled=true`、`version=1.3.0`。
4. 冒烟：`python -m unittest discover -s tests`（应 **321 通过**）；`python tools/image_eval.py`（应 120/120）。

## 7. 已知限制

1. **领域 × 风格承接率 100%（100/100）**（门槛 85%，T1 灰区 11-17、T2 禁配 11-17、T3 归位 11-18、v1.3.0 补 `概念设定` 11-20）；该指标只证明「点名的词落了地」，不等于画面好看，主观质量以盲评为准。词表外已清零，见 `docs/image-prompt/DOMAIN-STYLE-MAP-v0.1.md` §4.1。
2. **未成年人保护 / 在世艺术家署名**目前只有文档约定、无代码路径（计划 §9.6 已知缺口）。
3. **组件体积余量 2,027 B**（43,029 / 45,056，占 4.5%）：v1.3.0 分支下沉吃掉 2 KB，再加 UI 前必须先做 chips 懒加载或压缩。
4. **反馈数据为 0**：灰度观察期 2026-11-18 ~ 11-24，届时填 `docs/image-prompt/GRAY-REPORT-v0.1.md` §4。
