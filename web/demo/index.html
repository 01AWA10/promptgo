    三步接入

    不需要构建工具、不需要框架适配、不需要网络。

    STEP 1

    启动本地服务

    双击 start.bat，或执行 python server/app.py --port 7317。

    STEP 2

    引入组件脚本

    一行 script 标签，自动注册 <prompt-enhancer>，样式完全隔离。

    STEP 3

    放标签并绑定输入框

    用 target 指向已有 textarea，即可读取与回填。

    <!-- 1. 引入组件（自动注册，无依赖） -->
<script src="http://127.0.0.1:7317/prompt-enhancer.js" defer></script>

<!-- 2. 放到页面上，绑定已有输入框 -->
<prompt-enhancer
  target="#prompt-input"
  mode="struct"
  layout="bubble"
  theme="auto"
  label="提示词增强"></prompt-enhancer>

<!-- 3. 监听结果，接入你自己的业务逻辑 -->
<script>
  document.querySelector('prompt-enhancer')
    .addEventListener('pe:result', function (e) {
      console.log(e.detail.enhanced, e.detail.score);
    });
</script>
