## 1. 标注格式

| 列 | 含义 |
| --- | --- |
| 输入 | 用户原话，保留口语（含省略、比喻、情绪词） |
| 期望命中 | 术语表主词（`中文` 列原样），多条用 `/` 分隔 |
| 场景 | MK / EC / IL / AV / PS / CD |
| 难度 | A 直给（原话含词）· B 转译（口语→术语）· C 歧义（多解或冲突） |

评分口径：对每条计算 `命中数 / 期望数`，三维度分别取均值即召回率；门槛见 §5。

## 5. 门槛与报告口径

| 项 | 门槛 | 计算方式 |
| --- | --- | --- |
| 风格召回 | ≥90% | 20 条命中率均值 |
| 镜头召回 | ≥90% | 同上 |
| 光线召回 | ≥90% | 同上 |
| 不退化 | 不低于 v0.1 快照 | 同语料跑 v0.1 词典，逐条对比 |
| 歧义上限 | ≤3% | 一词语义跨类的词条占比 |

**报告须包含**：三张按难度分组的召回表（A/B/C）、未命中样例的归因（词表缺失 / 别名不足 / 冲突被降权 / 解析失败）、以及「新增词是否引入新歧义」的检查结论。

**注意**：C 难度样本（S20、以及后续加入的跨类混搭）**不计入召回**，单独统计「冲突检测准确率」，避免用歧义样本拉低词表评分。
