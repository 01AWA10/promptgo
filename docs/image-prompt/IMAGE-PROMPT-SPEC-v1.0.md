# 图像提示词结构规范 v1.0

> 阶段 2 交付物 · 2026-11-14 · 关联：[`../IMAGE-PROMPT-ITERATION-PLAN.md`](../IMAGE-PROMPT-ITERATION-PLAN.md)
> 输入依据：[`SCENARIO-MATRIX.md`](SCENARIO-MATRIX.md)（60 条语料）、[`VISUAL-TERMS-v0.1.md`](VISUAL-TERMS-v0.1.md)（188 条词）、[`INTENT-BOUNDARY-v0.1.md`](INTENT-BOUNDARY-v0.1.md)（30 条边界）
> 本规范定义「一句话 → 图像提示词」的**结构、必填规则、长度预算、平台方言与契约增量**，是阶段 3 词表与阶段 4 断言的共同基准。

## 1. 设计目标与约束

1. **可执行**：输出能被目标平台直接使用，不是描述性散文。
2. **可解释**：每个词来自哪一维可追溯（风格词来自 S5，负面来自 S8 等），便于归因与回归。
3. **确定性**：同一输入 + 同一选项，输出逐字符一致（无随机、无时间戳）。
4. **短**：中文 150–260 字（按场景分档，见第 5 节）/ 英文 40–120 words；模型对前 1/3 内容权重更高。
5. **安全**：不输出可识别真人、商标、版权角色、暴力色情描写。
6. **隔离**：仅 `intent=image` 走本结构，文本链路（8 段指令式模板）零改动。

## 2. 总体结构：8 段

| 段 | 名称 | 作用 | 必填 | 默认长度（中文） |
| --- | --- | --- | --- | --- |
| S1 | 主体与动作 | 画什么、几个、什么状态 | 是 | 20–50 字 |
| S2 | 场景与环境 | 在哪、何时、背景元素 | 是 | 20–40 字 |
| S3 | 构图与视角 | 怎么摆、从哪看、景别景深 | 是 | 15–30 字 |
| S4 | 光线与氛围 | 光从哪来、什么情绪 | 是 | 10–25 字 |
| S5 | 风格与媒介 | 像什么（摄影/插画/3D/流派） | 是 | 10–25 字 |
| S6 | 材质与细节 | 表面质感、细节密度 | 否 | 10–30 字 |
| S7 | 技术参数 | 比例、清晰度、平台参数 | 是 | 5–15 字 |
| S8 | 负面约束 | 排除崩坏与违规 | 是 | 20–40 字 |

**顺序不可调换**：主体最先（权重最高），负面最后（不污染主体语义）。S3/S4 先于 S5，是因为「怎么拍」比「像什么风格」更具体，能减少风格词对构图的干扰。

**与文本 8 段的区别**：文本模板是给对话模型的**指令**（角色/步骤/自检），图像模板是给绘图模型的**描述**。禁止复用「角色：你是…」「步骤 1/2/3」「自检清单」等结构——绘图模型不识别，且浪费 token。

## 3. 分段规范

### S1 主体与动作

- 必写：主体类型 + 数量 + 关键外观 + 动作/状态；可选：情绪、视线方向。
- 写法：名词短语优先，避免完整句。「一位短发女性，侧身回头，微笑」优于「画面中有一位女性，她正在回头看」。
- 反例：「一个很酷的东西」（无主体类型）、「很多人」（数量不可执行，改为 5–9 人）。

### S2 场景与环境

- 必写：地点 + 时间/天气（可选）+ 背景元素 1–2 个。
- 产品/头像类允许简化为「纯白无缝背景」「浅灰纯色背景」。
- 反例：「在某个地方」「背景随意」（不可执行）。

### S3 构图与视角

- 必写：构图法则（三分法/中心/对称/对角线/留白）+ 机位（平视/仰视/俯视/鸟瞰）+ 景别（远景…大特写）。
- 可选：景深（浅/深）、透视（广角/长焦压缩）。
- 海报/电商需写明留白位置（「右上留白」「中心留空」）。
- 反例：「构图好看」（无法执行）。

### S4 光线与氛围

- 必写：主光性质（柔/硬）+ 方向（侧/逆/顶）；可选：色温、时间光（黄金时刻/蓝调）、氛围（雾/颗粒/体积光）。
- 反例：「打光很高级」；改为「柔光 + 侧向轮廓光，暖色温」。

### S5 风格与媒介

- 必写：主风格 1 个 + 媒介（摄影/插画/3D 渲染）；最多加 1 个辅助修饰。
- 只允许**流派/年代/技法/媒介**，禁止在世艺术家、工作室、品牌名（见术语表第 11 节替换表）。
- 反例：「某艺术家风格」「某公司动画风」——合规风险，且平台可能拒绝。

### S6 材质与细节（选填）

- 写：表面处理（哑光/高光/拉丝/釉面）+ 1–2 个细节（水珠/纹理/反光）。
- 与 S1 冲突时不写（如「剪影」不写面部纹理）。

### S7 技术参数

- 必写比例；写画质词（高分辨率/细节清晰/低噪点）。
- 平台参数（`--ar`、权重、negative 字段）由**方言层**追加，不写进正文。
- 反例：正文里写 `--ar 16:9`（MJ 之外平台无法解析）。

### S8 负面约束

- 必含**通用 4 项**：低质量、模糊、文字水印、比例畸变（任何场景都写）。
- **条件项**：含人物/动物 → 加「多余肢体、面部崩坏」；写实场景 → 加「杂乱背景」；纯色/无缝背景的产品与头像可省「杂乱背景」。
- MJ 方言的 `--no` 只列违规项（文字/水印/logo/肢体），画质类由 `--v 6 --style raw` 承担，不写 `low quality`。
- 场景追加由场景矩阵决定（电商加「反光过曝/道具抢镜」，海报加「主体压字/边缘裁切」）。
- 安全红线**不写进负面词**，而是前置拦截或改写主体描述（理由见第 8 节）。

## 5. 长度预算与裁剪

**计数口径**：中文按字符数（含标点、不含空格）；英文按空格分词。

| 层级 | 预算 | 说明 |
| --- | --- | --- |
| 中文 · 多元素场景（MK / IL / PS / CD） | 180–260 字 | 低于 180 字通常缺维度 |
| 中文 · 单主体场景（EC 主图 / AV 头像 / 纯背景） | 150–220 字 | 单主体维度天然少，不靠堆词凑长度 |
| 中文硬上限 | 900 字 | 超限按裁剪顺序处理 |
| 英文 · MJ | 40–120 words（推荐 50–90） | 尾部参数占预算 |
| 英文 · Flux | 45–120 words | 完整句优先，禁止堆砌参数 |
| SDXL tokens | ≤150（含负面） | CLIP 77×2，超出会被截断 |
| 单段上限 | S1 ≤50 字，其余 ≤40 字 | 防止某一段吃掉预算 |

**裁剪顺序**（从先到最后）：S6 附加细节 → S3 次要修饰（景深/透视）→ S5 辅助风格 → S4 氛围修饰 → S2 次要背景元素。**永不裁剪**：S1 主体、S7 比例、S8 安全与基础负面。

裁剪后须在 `analysis.image.trims` 记录被裁段，便于评估「是否裁掉了关键信息」。

## 6. 缺失处理与默认值

| 缺失段 | 策略 | 默认值 |
| --- | --- | --- |
| S1 主体 | **追问**（唯一必须问的） | 无 |
| S2 场景 | 按场景默认 | 产品/头像：纯色背景；海报：渐变色背景 |
| S3 构图 | 按场景默认 | 头像/产品：中心构图 + 平视 + 中景 |
| S4 光线 | 默认 | 柔和自然光；产品为影棚柔光 |
| S5 风格 | 按场景默认 | 电商→商业产品摄影；头像→扁平插画；概念→电影感概念设定 |
| S6 材质 | 不补 | — |
| S7 比例 | 由用途推断 | 主图/头像 1:1；社媒 16:9；海报 2:3；分镜 21:9 |
| S8 负面 | 自动注入 | 基础 6 类 + 场景追加 |

**追问上限**：一次最多问 2 个（主体缺失 + 风格歧义），其余用默认并在 `analysis.image.defaults` 标注，不打断用户。

## 7. 平台方言映射

| 平台 | 正文形态 | 参数/语法 | 负面表达 | 长度 | 禁忌 |
| --- | --- | --- | --- | --- | --- |
| 通用（默认） | 中文自然语言短语，顿号/逗号分隔 | 无参数 | 句末「；避免 …」 | 180–260 字 | 不写平台参数 |
| Midjourney v6 | 英文自然语言短语 | 尾部 `--ar 16:9 --v 6 --style raw` | `--no text, watermark, logo` | 40–120 words | 参数混入句中；长从句 |
| SDXL | 英文逗号关键词 + 权重 | `(term:1.2)`，权重 1.0–1.3 | 独立 `negative_prompt` 字段 | 正文 ≤75 tokens，负面 ≤75 | 正负词重复；权重 >1.4 |
| Flux | 英文自然语言完整句 | 比例由 width/height 控制 | 句中 "avoid …" | 45–120 words | 堆砌参数与权重 |
| DALL·E 3 | 中文或英文自然语言 | 无参数 | 句中「不要出现文字」 | 建议 200–600 字符 | `--ar` 等参数语法 |

**方言层实现约束**：结构（S1–S8）只生成一次；方言层只做「语言切换 + 尾部追加 + 负面改写」，不允许改动 S1–S6 的语义顺序，保证同一输入跨平台可对比。

## 8. 负面约束与安全

**通用必备 4 项（默认注入）**：低质量、模糊、文字水印、比例畸变。

**条件项**：含人物/动物 → 多余肢体、面部崩坏；写实场景 → 杂乱背景。

**场景追加**：见第 4 节矩阵最后一列。

**安全红线（前置拦截，不进入负面词）**：

| 类型 | 处置 |
| --- | --- |
| 可识别真人肖像 | 改写为「虚构人物 + 人群特征」；拒绝指名真人 |
| 商标/品牌 logo | 去除品牌名，改为「无标识包装」；拒绝复刻 |
| 版权角色/IP | 改为特征化原创描述 |
| 暴力血腥、裸露、仇恨符号 | 直接返回 `SAFETY_BLOCKED`，不生成提示词 |
| 在世艺术家/工作室风格 | 替换为流派/年代/媒介 |

**为什么不做成负面词**：「no blood」这类否定在扩散模型中常被反向激活（提到即强化）。安全项必须在生成前拦截或改写主体描述。

**法务评审（2026-11-16）**：按 [`../IMAGE-PROMPT-ITERATION-PLAN.md`](../IMAGE-PROMPT-ITERATION-PLAN.md) §9.6 **E2 豁免**——
本期为离线、不联网、不出图的内部工具，无对外输出与商业化，法务评审无标的物；**接入绘图模型 API、
对外发布或商业化交付前必须补做**。

**代码覆盖现状（7 类红线）**：真人肖像（`SAFETY_SOFT`：明星/网红/真人）、暴力血腥、色情裸露、
仇恨/纳粹符号（`SAFETY_BLOCK`）、商标与版权角色（软红线改写）**已有代码路径**；
**未成年人保护、在世艺术家署名仍只有本节约定、无代码实现**，属已知缺口，不得宣称已覆盖。

## 9. 接口契约增量（向后兼容）

### 9.1 请求

```json
{
  "text": "做一张小红书种草的配图",
  "platform": "mj",        // generic(默认) | mj | sdxl | flux | dalle3
  "ratio": "4:5",          // 可选；缺省按场景推断
  "variants": 1            // 1–4；>1 时返回多段提示词
}
```

### 9.2 响应（仅 `intent=image` 时新增字段）

```json
{
  "ok": true,
  "enhanced": "…",
  "negative": "low quality, blurry, text watermark, …",
  "variants": ["…"],
  "analysis": {
    "intent": "image",
    "image": {
      "segments": {"subject": "…", "setting": "…", "composition": "…",
                   "lighting": "…", "style": "…", "texture": "…",
                   "technical": "…", "negative": "…"},
      "defaults": ["lighting", "composition"],
      "trims": [],
      "safety": {"blocked": false, "reasons": []}
    }
  }
}
```

### 9.3 元数据

`GET /v1/meta` 新增 `image` 分组：`styles` / `lighting` / `compositions` / `ratios` / `platforms`，总预算 ≤5 KB，整体负载 ≤12 KB。

### 9.4 兼容规则

- 文本链路响应字段与顺序不变；`negative`/`variants`/`analysis.image` 仅在图像意图出现。
- 老客户端忽略新字段即可；`platform` 缺省为 `generic`（不追加任何平台参数）。
- 安全拦截使用现有错误结构：`{"ok":false,"error":{"code":"SAFETY_BLOCKED","message":"…"}}`，HTTP 422。

## 10. 确定性与可测性

1. 输出只依赖输入、词典与选项，不依赖时间、随机数、外部网络。
2. 同输入同选项两次调用逐字符一致（阶段 4 用 `assertEqual` 守护）。
3. 每个词可回溯到维度：`analysis.image.segments` 与最终文本按段可对齐。
4. 自动断言可检查：8 段非空、基础负面齐全、长度区间、比例存在、禁用词为空、平台语法合法。
