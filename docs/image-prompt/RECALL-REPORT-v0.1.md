## 2. 口径（重要）

**行级召回**是门槛指标：一条语料只要命中任一期望术语即算接住。因为匹配器每个维度只输出 1 条，
而语料一行常写 2 个期望词（如「商业产品摄影/极简主义」），用「命中数/期望数」会导致指标被
维度设计人为压低——该口径仅作参考，实测 **72%（术语级）**。

**语料是词表探针，不是完整需求**：像「拍个大特写，看清材质纹理」不含产物词，整句意图判定不会
判为图像。因此 `intent_rate` 只有 15%，这是设计使然，不作为词表质量指标（意图判定由
`tests/test_image.py` 的 6 个场景用例与 `tests/test_image_eval.py` 的 120 条语料负责）。

**场景判定准确率**同理：语料碎片多无场景词。带场景词的 7 条里判对 4 条（57%），全量 28%——
后者无参考价值，故报告分列。

## 4. 首轮实测暴露的 3 个缺陷（已修）

| 缺陷 | 现象 | 修法 |
| --- | --- | --- |
| 别名缺口语层 | 召回仅 45%：用户说「黄昏」「压扁」「性冷淡」，词典只有术语 | 为 40 余条词加口语别名（`_ALIAS_EXTRA`），别名只影响召回，输出仍用主词 |
| 权重压过具体性 | 「全景接片，宽幅」被更短的「全景」吃掉 | 匹配顺序改为**最长匹配优先**，场景权重只在同长度词间区分（规范 §3 第 1 条） |
| 同形别名抢占 | 给 `微距镜头` 加「大特写」别名后，`大特写` 这一景别永远命中不到 | 撤回该别名，景别与焦段分离（镜头维度内不跨类复用别名） |

## 5. 复现方式

```bash
python tools/expansion_bench.py --image        # 人读报告
python tools/expansion_bench.py --image --json # 结构化结果
```

脚本直接解析 `docs/image-prompt/IMAGE-CORPUS-v0.1.md` 的表格，**不另抄一份语料**，
改语料即改基准，避免两侧漂移。

## 6. 残留风险

1. **术语级仅 72%**：一行写 2 个期望词时，单值匹配器只能给出 1 个。若后续要求一维多值，
   需改 `match_terms` 返回列表，并同步改渲染（最多 2 个词，权重截断）。
2. **口语别名可能过度召回**：把「卡通」挂到 `低多边形`、「复古」挂到 `复古海报` 这类泛词上，
   在长文案里可能误命中。当前靠最长匹配与领域禁配表兜底，尚未做误召回率评测。
3. **场景判定在碎片语料上不可用**：真实输入含场景词时准确率 4/7（57%），仍有提升空间，
   主要来自「主视觉/宣传图」与「海报/插画」的交叉。
